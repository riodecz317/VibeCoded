💡 How it works: No Azure app registration, sign-in, or Power Automate license needed. Pick the local folder that's synced to your SharePoint library via OneDrive — the app then writes the file directly into it on every save. OneDrive uploads it to SharePoint automatically in the background, same as any other file you'd drop in that folder.

⚡ Auto-save: once a folder is connected, any change you make is written automatically 30 seconds after you stop editing — no need to click Save yourself. You can still save instantly anytime with the button or Ctrl+S.

One-time setup:
  1. Make sure the SharePoint library is already synced (Sync button in SharePoint, or already showing under OneDrive in File Explorer).
  2. Click "Choose folder…" above and select that synced folder.
  3. Approve the one-time browser permission prompt — after that, saves are silent.

⚠️ Folder access only persists for this browser tab/profile. If you reopen the file later, you may need to re-pick the folder once.
